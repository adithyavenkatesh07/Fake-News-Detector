# 📰 Fake News Detector

A machine learning-powered web application that detects whether a news article is Fake or Real using Natural Language Processing (NLP) and a trained classification model.

## 🚀 Live Demo

🌐 Try the application here:

https://fake-news-detectorgi-rfdo58hx89ayv8rhnkyr5r.streamlit.app/

---

## ✨ Features

- Detects fake and real news articles
- User-friendly web interface
- Machine Learning-based prediction
- Instant classification results
- Deployed using Streamlit Community Cloud

## 🛠️ Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Joblib
